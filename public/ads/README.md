# Adsterra banner ads

Each standard banner runs in its own HTML document and iframe. Native Banner is
managed separately and is not generated by this workflow.

Set the banner keys in `.env.local`, `.env.production`, `.env.development`, or
the deployment environment, then run:

```bash
bun run ads:sync
```

`dev` and `build` run this command automatically. A missing key or the value
`0` disables that placement in the React component without throwing an error.

Supported variables:

- `NEXT_PUBLIC_AD_MOBILE_320X50`
- `NEXT_PUBLIC_AD_BANNER_300X250`
- `NEXT_PUBLIC_AD_BANNER_728X90`
- `NEXT_PUBLIC_AD_BANNER_468X60`
- `NEXT_PUBLIC_AD_SIDEBAR_160X600`
- `NEXT_PUBLIC_AD_SIDEBAR_160X300`
